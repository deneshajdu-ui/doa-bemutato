# Presentation analytics testing
Before any browser QA of the public presentation, open the canonical URL with `?doa_internal=1`, or first enable exclusion at /meresi-kizaras. Never open the bare presentation URL for routine QA. The test parameter bypasses both custom events and Cloudflare Web Analytics before either starts, and persists exclusion when localStorage is available. Subsequent pages in that browser stay excluded. Do not remove this flag for measurement tests on production; use local mocks/in-memory D1 instead. This does not exclude infrastructure access logs or third-party iframe telemetry.
Cloudflare Pages automatic Web Analytics injection MUST stay disabled (build_config web_analytics_tag/token null). analytics-gate.js loads the existing site's beacon conditionally. Do not re-enable auto-injection, which bypasses the exclusion. Preserve the Web Analytics site registration and history.
